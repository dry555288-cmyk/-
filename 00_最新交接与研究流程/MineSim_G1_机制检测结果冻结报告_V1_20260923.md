# 4. MCTS 搜索机制

## 4.1 active joint action domain

CandidateSystem binds this method as searcher.action_provider; each vehicle contributes its currently feasible actions and product creates A/B JointActions.

逻辑/公式：If hard safety or both goals reached, return \[\]; otherwise product(actions(A),actions(B)). Goal/stop and stopping-bound filters are inside DestinationStopTransition.actions/action_report.

参数：Four MCTS actions; A/B only; no external tokens.

作用域：合法动作 / 状态转移 / 终止/状态 / 搜索/回传

证据：.../runtime/candidate_mcts/dual_stop_adapter_v1.py  
DualStopFleetTransition.active_joint_actions L84-89

*备注：Unlike the generic Fleet active_joint_actions, the frozen candidate uses per-vehicle feasibility filters.*

## 4.2 timed search / iteration admission

Runs cooperative MCTS iterations until the work cutoff or reserve guard; only completed iterations finishing by cutoff update the admitted root snapshot.

逻辑/公式：work_deadline=start+400ms-20ms; stop if remaining\<=0, count\>=100000, or remaining\<=1.25\*max_completed_iteration_ns; late completed iteration is excluded. If no admitted root snapshot, raise NoAdmittedDecision; root action max=(visit_count,q,negative joint-action tuple).

参数：BUDGET_NS=400,000,000; RETURN_RESERVE_NS=20,000,000; GUARD_FACTOR=1.25; MAX_ITERATIONS=100000; gamma=.99;c_uct=1.4; fixed_iterations must be None in real path.

作用域：终止/状态 / 搜索/回传

证据：.../core/deadline_search_v2.py  
DeadlineFleetSearch.search/\_continue L66-187

*备注：A late/absent admitted action is not replaced by a fallback action.*

## 4.3 native UCT / expansion / backup

Inherited unchanged by timed search; selects fully-expanded nodes, randomly expands an untried action, rolls out to terminal/depth, backs up discounted values, and supplies root N/W/q fields.

逻辑/公式：UCT=q+c\*sqrt(log(parent_visits+1)/(child_visits+1e-6)); backup V=immediate_reward+gamma\*V; root final key=(visits,q,negative action tuple). Defaults in class are budget=300,max_depth=8,c=1.4,gamma=.99 but Retry2 binds budget=MAX_ITERATIONS and horizon 8.

参数：Retry2: budget=100000 guard, max_depth=8, c_uct=1.4, gamma=.99, seed pair native seed.

作用域：状态转移 / 终止/状态 / Reward / 搜索/回传

证据：.../runtime/candidate_mcts/fleet_search.py  
FleetMCTSSearch.search/\_select_uct/\_expand/\_rollout/\_backup L83-295

*备注：The timed subclass preserves inherited arithmetic and captures receipts; no tree reuse across online calls is configured, although the controller object persists its tree-independent search state only.*

## 4.4 rollout policy and Guide effect

Guide mode changes rollout suffix action choice only; tree expansion, legal domain, reward, backup, and root choice remain inherited native logic.

逻辑/公式：With alpha=.5, independent guide RNG requests a guided whole suffix with probability .5; guide chooses among original legal actions. If unavailable/inapplicable, rollout falls back to native random legal action. Alpha=0 is native uniform tracing.

参数：alpha=.5 for candidate V2; policy_seed separate; guide envelope is an ordering heuristic, not collision proof or pruning certificate.

作用域：搜索/回传

证据：.../parent/intent_rollout.py  
IntentRolloutSearch.\_rollout L150-223

*备注：Guide has no inter-search tree/intention memory and does not alter action legality.*

# 5. 动作空间、动力学与终点停车

## 5.1 destination-stop motion and actions

Computes each vehicle's one-dimensional bounded motion and rejects actions unable to stop within the goal upper bound.

逻辑/公式：Actions map BRAKE=-3, DECEL=-1.5, KEEP=0, ACCEL=1 m/s2; dt=.5 s; speed integrates to \[0,15\] m/s; route_s adds integrated distance. Action allowed iff next route_s\<=goal upper and stopping distance remains \<= upper; parked state allows KEEP only. No full-action fallback.

参数：dt=.5 s; accel_max=1; decel_max=3; max_speed=15; goal_window=.5 m; goal upper=goal_route_s.

作用域：合法动作 / 状态转移 / 终止/状态 / Reward / 搜索/回传

## 5.2 goal/park behavior

A vehicle becomes goal_reached only when route_s lies in \[goal_route_s-.5,goal_route_s\] and speed is exactly zero; newly parked time records the physical zero-speed event; subsequent action is KEEP and state remains parked.

逻辑/公式：goal_reached == (low\<=route_s\<=upper and speed==0); both vehicle goals are required for task completion.

参数：goal window width=.5 m

# 7. MCTS Reward 与外层 Return

## 7.1 active MCTS reward

The scalar returned by CandidateSystem.advance and used in rollout/backup.

逻辑/公式：For each vehicle not already parked: progress=w_p\*max(0,ds)/max(prev_target_speed\*.5,eps); speed=w_s\*(-abs(v-target)/max(target,eps)); legacy TTC term from lead slots; clearance term from physical minimum clearance; comfort=w_c\*(-abs(a1-a0)/.5/10); goal adds goal_bonus; hard safety subtracts max collision_penalty. Vehicle totals divide by 2, then internal clearance reward is added.

参数：RewardConfig defaults: w_progress=1,w_speed=.3,w_safety=2,w_clearance=0,w_comfort=.3,collision_penalty=100,goal_bonus=30,ttc_safe=3 s,clearance_safe=3 m,eps=1e-6; frozen dual-only scope forces external lead/safety to NONE/0 and reward_check uses safety=0. Fleet config supplies internal clearance weight/safe threshold.

作用域：Reward / 搜索/回传

证据：.../runtime/candidate_mcts/fleet_reward.py and reward.py  
FleetRewardModel.evaluate; RewardModel.evaluate L74-132

*备注：No time/wait, action-switching, cooperation, or deadlock reward term is in the active CandidateSystem scalar formula. Guide is rollout policy, not reward.*

## 7.2 outer return metric

Outer finite-window/full-task reporting only; it is not passed to FleetMCTS reward or backup.

逻辑/公式：finite_window_return=sum(.99^i \* step_reward_i); full_task_return equals it only for terminal outcomes, otherwise null; incomplete tail is censored and not bootstrapped.

参数：gamma=.99; cap supplied by outer evaluator (Retry2=128).

作用域：终止/状态 / 仅诊断

证据：.../runtime/teacher_cell_core.py
