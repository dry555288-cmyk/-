# 2. 项目主目标与冻结路线

- 主目标：用神经网络直接辅助 MCTS，在保持任务质量与安全性的前提下降低在线搜索预算/CPU/iterations/nodes，并把网络前向开销计入总成本。

- 冻结路线：G0 基线冻结 → G1 evaluation/safety/long-term value → G2 Teacher Budget×Depth → G3 高质量 Teacher → G4 标签审计 → G5 网络 → G6 lossless neural-guided MCTS → G7 confidence-gated pruning → G8 budget-quality curves → G9 independent HOLDOUT。

- 首轮神经集成禁止直接硬剪枝；如果 G6 不能在等质量下减少搜索，不能依赖 G7 强行制造速度提升。

- Teacher 标签是有限预算 MCTS 的近似，不是真值；未来标签审计要用跨 RNG 稳定性、排序/分布一致性，而不是只看一次 Top-1。

# 4. 已冻结的任务/机制语义

- Destination-stop dynamics：dt=0.5 s；动作加速度 \[-3, -1.5, 0, +1\] m/s²；速度范围 \[0,15\] m/s。

- 成功条件：两辆车均进入各自 0.5 m destination window 且 speed==0；route-end crossing 本身不是成功。

- CAP128 是 evaluation stop，不是 task terminal/success。

- Hard V2V：9×4 m 真实 footprint 的接触/相交，hard margin=0；3 m internal clearance 仅为 soft shaping reference。

- 当前 safety time-domain：只声明 0.1 s simulation lattice；不声明连续时间 between-ticks collision-free proof。

- Planning deadline failure 与 no-admitted-action 是独立 execution outcome，不能混成 deadlock。

# 7. Deadlock：已完成定义，尚未完成 terminal 集成

- 已 PASS 的定义版本：G1_SAFE_ABSORBING_DEADLOCK_V1。

- 不是 deadlock：hard-safety terminal、success terminal、任一 unfinished vehicle 正在运动、no-admitted-action execution failure。

- 如果 stationary safe unfinished state 存在任意 admitted joint action，且该 action 的 safe successor 能完成任务、增加任一 unfinished vehicle route_s 或产生正速度，则不是 deadlock。

- 只有所有 admitted action 都不能产生 safe physical escape，且存在安全 stationary continuation 时，才判 SAFE_ABSORBING_DEADLOCK。

- Policy stall（规划器反复选择等待）目前仍是 diagnostic，不等同于 task deadlock。
