ALGORITHM BASE / 冻结搜索语义

# 原生Fleet-MCTS：状态、动作与回传

FleetState共同表达两辆受控车；每车动作0/1/2/3分别为制动、减速、保持、加速，命令加速度为−3、−1.5、0、+1 m/s²。联合动作a=(aA,aB)，canonical index为4aA+aB；最大16种，实际合法域随状态改变。

| **阶段**  | **冻结源码语义**                                                             |
|-----------|------------------------------------------------------------------------------|
| Selection | 节点已充分扩展时，在现有子节点中按UCT选择；平分顺序来自动作排序。            |
| Expansion | 从untried_actions随机抽取一个动作，调用原转移，创建一个显式子节点。          |
| Rollout   | 在剩余名义时域内，从当时合法动作中rng.choice；到原终止条件即停。             |
| Backup    | 沿叶到根逐层加入进入子节点的即时奖励，再折扣后续值，更新N、W和Q。            |
| 根输出    | 按访问数N优先、平均Q其次、较小动作ID再次打破并列。每个外层周期只执行首动作。 |

Q(s,a) = W(s,a) / N(s,a)  
UCT = Q + 1.4 × sqrt\[log(Nparent + 1) / (Nchild + 10⁻⁶)\]  
G ← r(parent,child) + 0.99 × G  
a_exec = lexargmax (N, Q, −canonical_id)

上式UCT写出C01实际代码中的10⁻⁶稳定项；H10中的数学简式省略了该项。此处明确按已绑定源码表达，不静默把简式当逐字代码。C01内部elapsed_ms起止不覆盖全部准备／返回诊断，后续必须使用完整调用计时。

## 三个不能互换的数值

有限B、有限H、自适应访问得到的树内Q，不是完整任务最优价值。强制首动作后按某一策略续行的回报，也不是原树内Q。神经网络输出是特定训练目标下的排序分数，未经标定不能当碰撞概率或叶节点真实尾值。

H8表示从当前根开始最多8次0.5秒模型转换，名义4秒；它不保证显式统计树深达8层。后来的H16名义8秒，仍可能只有5—6层显式叶节点。

<span id="page_11" class="anchor"></span>LEARNING 01 / 旧神经算法

# Value V2/V3与K13的实际算法

神经网络已经研究并接入过，不是“尚未开始”。旧Value V2曾以ROOT_CENTERED_Q为目标；旧V3改为根内Q差加权成对排序，保留12→64→64→16两层ReLU结构。2356 roots来自6个episodes，对应37696条动作记录；不是2356个独立场景。

## 输入、损失与网络输出

旧12维包括A/B速度、A/B加速度、到冲突参考点剩余距离、绝对速度差、航向差及其除π值、双车同时处于approach／intersection标志和α3。完整状态仍须另存，12维特征相同不代表状态可交换。

dij = qi − qj；yij = sign(dij)  
wij = \|dij\| / max(qmax − qmin, 10⁻¹²)  
Lroot = Σ wij × softplus\[−yij(fi − fj)\] / Σ wij

历史设计按场景、场景内root等权，Adam学习率0.001、固定600轮；完整逐轮曲线未保存，不能将训练完成改成充分收敛。该损失的Q差权重是项目适配，不读取动作访问支持或回报方差；低支持的大Q差可能被赋予强监督。

## 实际接入是根排序，不是PUCT或叶价值

scorer先计算根特征，加载冻结归一化与checkpoint，输出16分数，改变根untried_actions顺序；树内UCT、rollout与backup不变。仅排序而不降预算，网络前向可能增加开销。

| **门控**          | **方法**                            | **冻结参数**                |
|-------------------|-------------------------------------|-----------------------------|
| margin \< τo      | PURE_FULL：原顺序／全动作           | τo=0.06767839193344116      |
| τo ≤ margin \< τp | NEURAL_ORDER_FULL：神经排序／全动作 | margin=top1分数−top2分数    |
| margin ≥ τp       | NEURAL_TOPK_PRUNED：只在根保留Top13 | τp=1.2940582036972046；K=13 |

margin不是校准正确率或Top13/14边界差；每个root在门控前支付一次forward。异常空候选执行full recovery。新26／36维模型与旧12维checkpoint不能混用。

MODEL CONTRACT / 新双车停稳

# 新停稳模型与冻结奖励

当前研究模型为DUAL_ONLY_DESTINATION_STOP_CANDIDATE_V1：仅A/B受控、无external traffic、固定路线、只前进；外层dt=0.5秒，vmax=15m/s。每车后轴位置进入自身终点前0.5米窗口且速度严格为0才parked；不吸附位置、不把近零速度归零。

parked ⇔ goal_upper − 0.5 ≤ s ≤ goal_upper 且 v = 0  
合法动作必须满足：s_next + v_next² / (2×3) ≤ goal_upper

BoundedMotion按恒命令加速度积分；达到0或15m/s边界后余时保持该速度。临近终点比较用精确二进制浮点的Fraction复核，ULP带只决定计算精度，不放宽物理边界。已parked只允许KEEP；无合法动作显式TerminalInfeasible，不恢复全域、不伪造碰撞。

## 奖励含义与当前诊断为什么会涉及起步代价

r = (Σ未完成车辆 \[进度项 + 速度项 + 舒适项 + 首次停稳奖励\]) / 2  
− 0.5 × clip01\[(3 − dAB)/3\]² − 100 × I(hard)  
进度项 = max(0, Δs) / (vtarget × 0.5)  
速度项 = −0.3 × \|vnext − vtarget\| / vtarget  
舒适项 = −0.3 × \|anext_command − aprev_command\| / (10×0.5)

已绑定C11配置vtarget=10.5m/s、单车goal_bonus=30，Fleet分母固定2，单车首次停稳贡献15。双车无外部对象时外部安全项为0；命令加速度用于旧奖励约定，实际端点／平均加速度另存。先停车辆不再贡献普通单车奖励，但车体继续参与另一车的碰撞检查。

> 3米是软净距惩罚尺度，不是获准的3米硬安全门槛。几何来自1米路线缓存、0.1秒采样；Controller跟踪、连续物理安全、生产道路可行驶真值未因此得到保证。后续对话声明保持这些模型与奖励不变；最新发布字节仍须原件核对。

## 为什么另立Y64，而不是“把CAP补成成功”

8状态×2首动作×4重复的Discovery64有48停稳、16CAP。按完整任务回报，只得到contrast_04一条候选，另外6状态截尾、1状态重叠；未知尾段不能补0。看过这批结果后另立固定窗口目标，变更时序与原结果分别保存。

Y64(s,a,ξ) = Σ\[k=0 … min(Tterminal,128)−1\] 0.99ᵏ rₖ  
Δ(s) = mean(Y64 \| 强制0,3) − mean(Y64 \| 强制3,0)  
回归目标 = Δ(s) / 100

首次强制动作奖励从k=0计入。运行满128步的CAP具有完整有限窗口Y64，但完整任务尾段仍null；技术中断或规划迟到导致窗口未完成时，Y64也不能冒充完整。100是数值缩放，不是统计阈值。

Gnew = Σ γᵏ rnew\[k\]，从新根起至H8或真实终止  
m个继承且修正贡献 + (64−m)次新增迭代 = 64个根贡献

非根backup包含进入该节点的即时奖励；可能合法存在root-only贡献，child visits合计63而root64，不能补造第64个子访问。状态不兼容可回退全新搜索，证据损坏则HOLD。历史样本相关且自适应选取，修正时域不等于无偏或独立模拟。

## 均匀随机模拟并不等于中性驾驶

E\[命令加速度\] = (−3−1.5+0+1)/4 = −0.875 m/s²  
两车都静止且16动作均合法时，9/16=56.25%的联合命令都不启动任何车
