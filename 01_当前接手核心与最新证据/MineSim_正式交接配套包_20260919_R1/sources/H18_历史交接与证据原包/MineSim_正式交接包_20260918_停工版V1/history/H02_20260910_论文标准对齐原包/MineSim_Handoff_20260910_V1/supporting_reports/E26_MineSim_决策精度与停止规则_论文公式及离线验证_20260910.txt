一、本轮实际完成什么
已经实现一个可执行的“同时置信区间—候选动作—停止状态”判定组件，并用两个现有冻结ZIP进行离线回放。
本轮没有启动MCTS、没有执行状态转移、没有随机rollout、没有模型前向、没有训练、没有实际删除动作，也没有批准新采样。
实现的是停止判定组件与可行性分析，不是完整的LUCB采样器，不是上线策略，也不是教师标签已经通过统计认证。
任务容许回报损失epsilon、正式统计错误预算delta、下一轮资源预算和外层随机流采样方案仍没有获得任务依据或授权；它们保留为null，不从旧结果反向选择。

三、继续明确估计目标，避免换一个公式就偷换任务
对固定根状态s、固定第一动作a，之后由冻结原生B64/H8策略pi接管，定义：
    Y_128(s,a)=sum_{k=0}^{min(128,tau)-1} gamma^k r_k；gamma=0.99。
    mu_128(s,a)=E[Y_128(s,a)]。
样本单位为一次外层执行轨迹，不是树节点访问或树内rollout。
真实终止tau按冻结模型定义：硬安全违反或两车达到配置路线进度。64秒是评价上限，不是MCTS树深，也不要求末端停稳。
现有384条轨迹均在上限之前真实终止，所以这384个样本的有限窗口回报与其各自终止回报相同。但不能由此证明期望mu_128与不设上限的任务价值相同：未来随机流仍可能发生截断。
本轮置信公式严格对应有限128步的mu_128。未终止样本仍进入有限窗口均值，而无限/完整任务尾部标为未知，不只平均成功样本。[R4]
这不是Q*、不是碰撞风险约束，也不是直接替换网络分数或旧教师Q的授权。

四、停止公式改进：不能让一个动作和它自己比出虚假不确定性
上一轮给出的充分条件为 max_b U_b - L_a <= epsilon。它是保守的充分条件，并非一般错误；但其中包含b=a时，加入了U_a-L_a。只要a自身区间仍有正宽度，epsilon=0就不能通过该条件，即使a的下界已高于所有竞争动作上界。
现在改成：
    Rplus(a) = max(0, max_{b != a}(U_b-L_a))。
当所有真实均值同时落在相应区间时：
    max_b mu_b - mu_a <= Rplus(a)。
证明：b=a的差值恰好等于0；对每个b!=a，mu_b-mu_a <= U_b-L_a。对所有竞争动作取最大值即可。
事实上，Rplus(a)是各动作区间组成的矩形集合上简单遗憾的最大值；本轮通过枚举小型区间盒的所有顶点做了测试。
新的精度停止条件：
    Rplus(a) <= epsilon。
epsilon=0允许在区间分离时识别一个最优动作，而不是要求被选动作本身的区间缩为一个点。若只在边界相等时停止，可证明最优但不证明唯一最优；严格唯一需L_a>max_{b!=a}U_b。
排除动作a的充分条件仍是：
    U_a < max_{b != a} L_b。
没有证据就保留。不能因为均值不在Top4或Top13就删除。
例如A=[9,10]、B=[7,8]：旧式含自身条件得到1，epsilon=0不能停；新式对A得到max(0,8-9)=0，可以识别A。此为合成公式测试，不是MineSim实际回报。
论文依据：[R2]第II节和式(1)中的经验候选与其他竞争臂比较。本轮epsilon表达式是项目的代数适配；没有实现其完整AE/UCB/LUCB采样策略或继承其样本复杂度保证。

五、本轮新增的方差敏感区间：经验Bernstein界
5.1 原论文
Maurer与Pontil [R1] Theorem 4针对[0,1]内i.i.d.样本给出单侧经验Bernstein界，其中样本方差是无偏方差，等价于sum_{i<j}(x_i-x_j)^2/[n(n-1)]。

5.2 项目适配到原始回报单位
设Y属于预先有效的[ell,u]，R=u-ell，n>=2，样本方差s_n^2采用n-1分母。对上下两侧各分配alpha/2，得到：
    c_n = sqrt(2*s_n^2*log(4/alpha)/n)
          + 7*R*log(4/alpha)/(3*(n-1))。
    L=max(ell,mean-c_n)，U=min(u,mean+c_n)。
注意log(4/alpha)来自两个单侧事件，并不是将原论文的log(2/delta)照抄后漏掉另一侧。
这是均值的置信区间，不是未来单条轨迹的预测区间；样本方差小不能把第二个范围项删除。
实现没有把样本最小/最大值当总体界，没有未经检验使用正态置信区间、bootstrap或“均值±1.96SE”代替有界样本保证，也没有声称经验Bernstein在小n时一定比Hoeffding更紧。

5.3 总体回报范围沿用经源码审查的保守界
两个目标根均target_speed=10.5，速度[0,15]，加速度[-3,1]，dt=0.5；lead_distance>=0，内部净距权重0.5。
每步非终止奖励下界-3.04，上界10/7；两车平均后目标奖励总额至多30；硬安全终止至多扣100且停止。
    S=(1-0.99^128)/(1-0.99)=72.3748332300791。
    ell=-3.04*S-100=-320.01949301944046。
    u=(10/7)*S+30=133.392618900113。
    R=453.41211191955347。
这些是冻结配置特有的保守推导，不证明紧致；不适用于擅自变化后的奖励。源代码和协议已复制到审核包source_evidence目录，代码不导入执行这些源码。

六、不能反复查看直到碰巧出现满意结果：跨动作、跨检查次数分配错误预算
Howard等 [R3]说明时间一致置信序列需要同时覆盖整个观察时间范围；不能将反复查看的数据一直当作一次固定样本量检验。
本轮采用一个简单可审查的项目构造，而非[R3]的stitched/mixture边界：
    alpha_{m,k}=delta/[M*k*(k+1)]，M=32。
这里m为两个状态的32个状态—动作条目；k为预先登记检查点的编号，不能在追加一批seed后重置为1。
    sum_{m=1}^M sum_{k=1}^infty alpha_{m,k}=delta。
由[R1]单次两侧界和并集界，在各固定动作跨重复样本i.i.d.、范围有效、检查点样本数预先确定等条件下，所有动作、所有登记检查点的区间同时有效。
不同动作可共享同一个重复索引，不要求动作之间相互独立；但每个固定动作的跨重复样本必须满足相应独立同分布假设。
历史中用固定连续整数seed并不自行证明这些统计条件。本轮没有认证Python伪随机流独立性；软件复现通过不能当成统计独立性的证明。
后续若设计新采样，应先固定外层随机流的生成分布、重复处理、失败/截断保留方式和检查点。没有自动生成新seed，没有把旧数据重新包装成符合新协议的前瞻样本。
允许将当前区间与早先登记检查点的区间取交集；若交集为空，按HOLD处理，不自动放宽或修成能PASS的区间。

    step73：16/16动作保留，严格最优条件未通过。

另外对假设检查点n_k=8*2^(k-1)做纯代数可行性计算，没有产生任何新轨迹。
仅看经验Bernstein第二项，哪怕样本方差恰好为0，界中仍有以下半径项：
    每动作n=128：93.7084；两个状态合计4096条轨迹。
    每动作n=256：48.0664；合计8192条。
    每动作n=512：24.5818；合计16384条。
    每动作n=1024：12.5388；合计32768条。
表中为此公式在给定范围/alpha分配下的原始范围项，不是所有可能算法的样本复杂度下界，不是未来区间宽度的精确预测，也不是采样计划或预算授权。边界裁剪会改变最后区间宽度，不能把该项直接当每个动作的最终遗憾。
不能因此断言必须采32768条；相反，当前没有任务epsilon与预算依据，不应直接启动这些规模。

九、已经实现的停止状态机
1. 规格未就绪：epsilon没有定义，或统计设计未经批准 -> HOLD_SPECIFICATION；不启动采样。
2. 规格获准且满足Rplus(a)<=epsilon -> PRECISION_MET_CONDITIONAL；输出符合条件的候选，而不是经验均值硬判第一。
3. 条件未满足、批准预算尚有余量 -> CONTINUE_WITHIN_APPROVED_BUDGET。
4. 条件未满足、批准预算已耗尽 -> BUDGET_EXHAUSTED_UNRESOLVED；不强行输出获胜动作，不自动加seed/调epsilon/delta。
5. 来源SHA、非有限值、区间逻辑、状态记录异常 -> 技术HOLD；不能作为科学优劣结果。
目前这只是可调用的纯判定组件。所有实际数据输出均为RETROSPECTIVE_CONDITIONAL_ONLY；没有由函数结果驱动MCTS采样、建立训练mask或删除动作。

十、任务容忍度不擅自代填
本次将epsilon_task、production_delta、new_sample_budget、new_seeds都保存为null。
epsilon=0只用于严格最优的软件诊断，不等于替用户确定了实际任务必须严格最优。
epsilon>0表示可容许的期望折扣回报损失，但当前奖励是进度、速度、TTC、舒适性、内部净距、目标奖励、硬安全惩罚的混合；“一个回报单位”等于多少秒延误或允许多少安全风险，不能未经分析就换算。
统计错误预算delta也不是碰撞概率上限。基于期望回报的近优保证不等同于物理安全保证。
下一轮正式采样前，须明确任务容许损失/严格目标、统计错误预算、外层随机流设计和计算上限。不能用本批均值差0.0915或0.2695反向选一个恰好通过的epsilon。
已实现的判定器可以在这些参数获得依据后复用；没有安排“再加8个seed直到结果稳定”。
