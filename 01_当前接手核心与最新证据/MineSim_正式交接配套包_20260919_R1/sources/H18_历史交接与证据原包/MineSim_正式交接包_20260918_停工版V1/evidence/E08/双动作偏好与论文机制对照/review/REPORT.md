## 2. 文献范围及读法

本报告优先以用户提供PDF版本为依据。公开网页仅核对论文来源、作者发布页和会议/期刊信息；不以类似题名的roundabout论文替换用户的intersection论文。页面号均为PDF从1开始的页码。已直接渲染查看下列关键公式、算法与表格页，不依据既有AI总结补写论文。

### P1 Safety-Critical Multi-Agent MCTS for Mixed Traffic Coordination at Unsignalized Intersections

用户原文件：可参考论文.7z/362388.pdf，16页。作者机构发布页：https://eprints.gla.ac.uk/362388/ ，DOI 10.1109/TITS.2025.3598727。

- 第6—7页，算法1及式22—25：对树中节点做V2V、V2H、V2R阈值检查，识别不安全节点并终止其继续搜索。属于安全依据的分支排除，不是网络预测低收益就允许删除。
- 第7页式26：安全动作集合中，结合Q_pred引导动作与随机动作构成混合rollout；Q_pred被称为learned value predictor。这里是搜索内部续行策略，而不是仅在原始状态对两个动作给一次分数。
- 第9页式41—43：实际选定子节点后，把该子节点作为新根，保留其子树供下一周期热启动，丢弃其他分支。状态与风险仍需更新检查。节省的是相邻周期重复建树/探索。
- 第9页复杂度讨论：提到不安全剪枝、UCB选择与潜在并行。潜在并行不是已量化并行加速实验。
- 第11页表II：Baseline列21.3±4.2s，Ours lmax=8列26.2±3.9s；第13页表III为24.9±3.6s和29.7±5.1s。表头为Average Simulation Time(s)，正文又使用computation time表述，不把它当作每帧规划延迟；这些表不支持“比其自身基线更快”。
- 已读版本未给足Q_pred网络层数、监督数据构造、训练损失等可直接复现的完整配方，不能把我们的26维/36维、固定64秒两动作回报差当成该论文规定。
- 式26给出混合安全rollout，但式27扩展序列又写作从联合动作域均匀采样；这是上传版本的表达衔接限制，不擅自消除差异或宣称完整代码级复现。

### P2 Driving Maneuvers Prediction Based Autonomous Driving Control by Deep Monte Carlo Tree Search

用户文件：接下来方向.7z/基于驾驶行为预测与深度蒙特卡洛树搜索的自动驾驶控制.pdf，13页。IEEE TVT，DOI 10.1109/TVT.2020.2991584。作者代码页面：https://github.com/winds-line/deep-MCTS ，IEEE记录：https://ieeexplore.ieee.org/document/9082903 。此处不执行作者代码。

- 第5—7页，式6—17与算法3：VSP根据图像状态和动作预测虚拟下一状态；AVP输出动作先验p和状态价值v。p进入节点选择的置信项，v用于叶节点评估/回传；最终动作由根访问分布得到。算法展开所有该层动作，不是把网络未选中的动作直接删掉。
- 第7页式17：AVP训练包含与MCTS访问策略π的交叉熵，以及(r+γv_next−v)^2价值项；并非两个首动作的64秒终局均值差。动作头是单车11种转向动作，与当前双车16种纵向联合动作不是同一接口。
- 第8页：训练阶段MCTS迭代1000、深度8；测试阶段迭代100、深度4。这是作者实验设置，不等于我们的系统可以直接采用同样预算。
- 第9页训练效率比较：AVP约40000步收敛，对照DQN约80000步等；所谓训练效率改善不能翻译为在线MCTS耗时减半。主要实验指标还包括转向连续性和轨迹偏差；未从上传版中得到当前MineSim同条件规划延迟提速比例。

### P3 Risk-aware unsignalized intersection management in unstructured mixed-traffic environment: a real-time hierarchical safety evaluation method

用户文件：可参考论文.7z/1-s2.0-S0968090X26003761-main.pdf，25页。DOI 10.1016/j.trc.2026.105890，出版社记录：https://www.sciencedirect.com/science/article/pii/S0968090X26003761 。分析按上传版本，不对未实时核验的现场部署作断言。

- 第3—5、10—14页：高层搜索候选通行顺序；给定候选，RA-MVSFM产生模拟轨迹，风险场评价轨迹安全。高层MCTS节点为部分通行序列，不是我们的每0.5秒两车联合加速度。
- 第14页6.1：通过UCT引导搜索，避免穷举全部排序。候选评估使用给定规则的zero-DOF前向模拟；zero-DOF不是车辆不能移动，而是不在每个候选评估中求完整连续控制优化。
- 第14—15页6.2：选定顺序后才进行OCP轨迹优化，并使用模拟轨迹作为初值；安全走廊与相对安全走廊将相关碰撞约束转成便于求解的形式。
- 第15—16页6.3：按车辆批次触发一次计算，在控制区行驶时间内完成，进入穿越区后执行；实时性要求计算小于控制区时间窗口，不等于每0.5秒重算一次全部策略。
- 第16页实验环境：Apple M4 Pro CPU 4.1GHz、48GB，无GPU。第18页表4给4—14车/批总计算1373.46—2615.54ms；5车/批1542.35ms。
- 第23页表8：所提方法1542.35ms，MCTS-Search基线13985.25ms。第22页明确runtime包含路权确定与轨迹规划，是该论文系统级对照，不是我们的双车MCTS同条件提速实验。

### P4 Path Planning using Neural A* Search（补充，非MCTS）

用户文件：接下来方向.7z/基于神经 A 搜索的路径规划.pdf，11页。作者会议原文：https://proceedings.mlr.press/v139/yonetani21a/yonetani21a.pdf 。

- 第2、4页：编码器生成guidance map，通过可微A*搜索，训练目标比较搜索历史closed list与专家路径，鼓励少展开非必要节点。
- 第6页评价同时看路径最优性和节点展开减少，不是只看网络拟合误差。它针对A*路径搜索，不能把它当作已实现的Fleet-MCTS剪枝方案。

## 3. 与当前项目的差异及结论

原两动作64秒目标和此次逻辑偏好器，是本项目的探索性代理目标，不是对上述任何论文完整训练方法的逐式复现。它们可帮助诊断预测能力，但离线损失变化没有直接证明搜索成本改变。

论文效率机制分别作用于不同计算：安全过滤减少继续探索的无效分支；策略先验改变探索分配；叶价值减少深层续行估值需求；树复用减少相邻规划周期重复工作；分层便宜前向模拟与批处理改变一次计算的对象、代价和触发频率。收益是否抵消额外推理/风险检查成本，只能由对应系统实测；论文设想和实验支持范围分开。

本轮结论为：技术执行完整、动作偏好无优势、在线搜索收益未测试。当前代理模型不具备可靠的剪枝证据，但不能据此否定MCTS、所有神经辅助搜索或其他效率方法。原32状态512条数据不追加；原有结果不修改；本次仅解释方法差别，不进入新试验。
