# 双车固定512条：训练组标准化的8次岭回归对照
资源 LOW，单进程CPU，不需要GPU。正式数据盘 /root/autodl-tmp。

本轮的原因：新增交互特征后，岭回归和小网络仍未同时优于常数的MAE/RMSE。当前冻结结果保留。
下一项新开发对照只检验输入的统计尺度和现有岭回归约束是否相配，不承诺改善。

- 不重新采样，不新增特征，不改变32状态/512条回报/8来源组。
- 当前36维岭回归的8折均选中lambda=1.0，本次直接保留这个值，不再运行内层选参。
- 每折只用28个训练状态计算列均值及总体标准差；训练标准差不大于1e-12的列，两侧置零并留标记。
- 新拟合共8次36x36小矩阵求解。没有神经网络拟合、2000步更新或旧模型复跑。
- 固定64秒回报及CAP语义不变，不从未知关系生成硬标签，不按结果删状态。
- 只与当前冻结常数及原36维岭回归同分母比较；原26维岭回归仅保留作上下文对照。
- 这是看过历史结果后的同路线开发对照，不能称独立盲测、MCTS加速或安全认证。
